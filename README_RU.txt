KinoKino 0.4 — Windows installer builder

Новые функции:
- Реальный каталог TMDB: тренды, поиск фильмов и сериалов, карточки с постерами и описаниями.
- Настройка TMDB API Read Access Token через кнопку ⚙. Токен сохраняется локально.
- Поиск на Кинопоиске по запросу открывается по кнопке справа или Enter (без автоматического открытия вкладок на каждый введённый символ). Автоматическая проверка соответствия TMDB ↔ Кинопоиск без API/разрешённого источника не заявляется.
- Избранное и история с локальным сохранением.
- Встроенный HTML5-плеер: прямые MP4/WebM ссылки и HLS (.m3u8) через hls.js. Нужен прямой URL на контент, который пользователь вправе смотреть; страница сайта не является видеопотоком.
- Нет рекламы, аналитики и регистрации внутри KinoKino.

СБОРКА WINDOWS:
1. Установи Node.js LTS с https://nodejs.org/
2. Распакуй архив.
3. Запусти build.bat.
4. После сборки установщик будет в dist\KinoKino Setup 0.4.0.exe

TMDB:
Получить API Read Access Token: https://www.themoviedb.org/settings/api
Открой KinoKino → ⚙ → вставь токен → Сохранить.
Данные TMDB используются по условиям TMDB; требуется соблюдать их атрибуцию и правила брендинга.

Ограничения:
- Архив — проект для сборки Windows установщика, не готовый EXE.
- Для сборки APK нужна отдельная Android-реализация (Media3/ExoPlayer).
- Плеер не извлекает видео с сайтов, не обходит DRM/платные подписки и не преобразует чужие URL в адреса другого домена.
