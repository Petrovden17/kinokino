# KinoKino 1.0 — Flutter project

Кроссплатформенная кодовая база приложения для Windows, Android и дальнейшей адаптации под Android TV.

## Добавлено в текущей итерации
- Детальная страница фильма/сериала: описание, жанры, дата, рейтинг TMDB, актёрский состав.
- Подбор похожего контента и рекомендаций TMDB.
- Каталог фильмов и сериалов с выбором типа.
- Фильтрация по жанру и минимальному рейтингу.
- Сортировка по популярности, рейтингу, дате и сборам.
- Локальные пользовательские оценки (миграция SQLite до версии 2).

## Уже присутствует
- Тёмная тема и адаптивная сетка.
- TMDB тренды и мультипоиск.
- SQLite: избранное, история, оценки.
- Локальные профили, пароль, код восстановления и детский PIN.
- Настройки, базовый родительский рейтинг, экран библиотеки.
- Базовый плеер для пользовательских HTTPS-ссылок на легальные потоки.
- Экспорт настроек и GitHub Actions для Windows и Android APK.

## Настройка
Добавьте `TMDB_API_KEY` в GitHub Repository → Settings → Secrets and variables → Actions. TMDB предоставляет метаданные, а не видеопотоки.

## Проверка и сборка
Требуется Flutter SDK:
1. `flutter create --platforms=windows,android .`
2. `flutter pub get`
3. `flutter analyze`
4. `flutter test`
5. `flutter build windows --release --dart-define=TMDB_API_KEY=ВАШ_КЛЮЧ`
6. `flutter build apk --release --dart-define=TMDB_API_KEY=ВАШ_КЛЮЧ`

## Что всё ещё не завершено
PiP, выбор аудиодорожек/субтитров/качества (зависит от формата и платформы), полноценный детский PIN-gate и расписание, применение возрастной классификации к каждому элементу каталога, загрузки с проверкой прав источника, шифрованные резервные копии всей БД, Chromecast, реальные push/system notifications, полноценная локализация интерфейса, onboarding, автоматическая диагностика и обновления, отдельная Android TV адаптация и тестирование устройств. Не заявляем эти функции готовыми до интеграции и тестов.
